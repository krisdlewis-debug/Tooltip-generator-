WoW Tooltip Forge — iPhone Home Screen Web App

This is a standalone Progressive Web App (PWA), not an App Store binary.

DEPLOY (free GitHub Pages):
1. Create a public GitHub repository named wow-tooltip-forge.
2. Upload all the files from this folder into the repository root (not the ZIP itself).
3. Open repository Settings > Pages. Under Build and deployment, select Deploy from a branch, main, /(root), then Save.
4. Wait for GitHub to show your secure https://<username>.github.io/wow-tooltip-forge/ address.
5. Open that URL in Safari on iPhone. Tap Share > Add to Home Screen > Add.
6. Open Tooltip Forge from its new Home Screen icon. Open once online to cache files for offline use.

The app automatically saves projects locally on the device/browser. Use Copy Project for an external backup.
Print PNGs at 100% / actual size, not Fit to Page.

No hosting or publication has been performed by ChatGPT.
